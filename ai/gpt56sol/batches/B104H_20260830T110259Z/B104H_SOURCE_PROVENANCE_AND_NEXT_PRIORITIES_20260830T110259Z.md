# B104H — mapping release, provenance assessment, and remaining priorities

## Canonical node mapping

A compact 56,944-row GraphSAGE-node-to-Entrez table and an evidence-rich companion table were generated. The evidence table includes:

- exact source OhmNet edgelist member and decompressed SHA-256;
- legacy CPython 2 dictionary slot and table size;
- prior independent-resolution basis;
- GraphSAGE and OhmNet neighbor-set hashes;
- observed and independently reconstructed feature-vector hashes;
- observed and independently reconstructed GO-label-vector hashes;
- row-level exactness flags.

Every row passes all three downstream checks: topology, features, and labels.

## Certainty levels

### Exact observations from available bytes

- Each of the 24 GraphSAGE graph blocks has the same Entrez-node set and edge set as its assigned OhmNet tissue network under the recovered mapping.
- All 2,847,200 feature cells and all 6,890,224 label cells are exactly reproduced.
- The compact node map is deterministic and internally complete.

### Strong historical-mechanism inference

- Original OhmNet node strings were inserted in edgelist order into a 64-bit, unrandomized CPython 2 dictionary and emitted in dictionary-table order.
- This inferred mechanism agrees with all 56,411 identities established without it and resolves the remaining 533 rows.
- The exact feature-selection implementation is not known even though a simple MSigDB procedure reproduces the matrix exactly.
- Six GO-column names remain provisionally oriented because three term pairs have identical vectors on the graph-gene universe.

### Documentary provenance

The OhmNet manuscript describes the global network as a composite experimentally supported physical interactome assembled from multiple resources, not BioGRID alone. Tissue-specific networks were generated by filtering that global physical network using tissue-activity information.

### Still open

- Original preprocessing source code and environment.
- Exact 24-of-144 tissue-selection and 20/2/2 split rule.
- Literal feature threshold operator (`>=200` versus `>200`), cap implementation, and MSigDB release.
- Proven orientation of the six duplicate-vector GO columns.
- Whether labels were generated directly from GOA v159 or from an Entrez-native product with the same effective annotations.

## PPI edge provenance: recommended final audit

GraphSAGE-to-OhmNet provenance is already established by exact node/edge equality. The remaining high-value edge check is one level upstream:

1. Compare the union of the supplied 144 OhmNet tissue networks with BioSNAP's `PPT-Ohmnet_tissues-combined.edgelist.gz`.
2. Confirm that the union is a subset of BioSNAP's `PP-Pathways_ppi.csv.gz`, whose published 21,557-node/342,353-edge statistics exactly match the global network described in the OhmNet manuscript.

The two files total roughly 4.4 MB. A single download-and-verify script accompanies this report.

Even a perfect match would establish the flattened global network, not attribute each edge to an individual source database. Per-edge attribution to IntAct/MIntAct, Rolland et al., BioGRID, HPRD, CORUM, and the Menche interactome is likely impossible without a source-bearing intermediate table.

## Alternate copies with label names

A broader search covered:

- the original GraphSAGE repository and open issues;
- DGL, PyTorch Geometric, and DeepGNN copies;
- GitHub mirrors and teaching/challenge repositories;
- BioSNAP metadata and OhmNet-related files;
- Zenodo, Figshare, Hugging Face, Kaggle, and general web search using exact filenames and candidate GO IDs.

No public copy containing the 121 original label names or a preprocessing script was found. Downstream copies preserve anonymous arrays or generic columns such as `label_0` through `label_120`. The original GraphSAGE issue tracker contains requests for protein-ID mappings and preprocessing code, but no released mapping or script.

This is evidence of an unsuccessful broad search, not proof that no copy exists. The most promising remaining routes are author contact, private lab archives, old machine backups, and an archived ordered intermediate term list.

## Recommended transition

After the small BioSNAP edge audit, further provenance searches have diminishing expected return. The project is ready to shift emphasis to:

1. a frozen, minimal reproduction package;
2. an evidence-graded scientific report;
3. independent verification instructions;
4. the randomized-label leakage experiment;
5. a gene-disjoint benchmark redesign.

### Running the BioSNAP audit later

```bash
python download_and_verify_biosnap_ppi_sources.py \
  --ohmnet-tar /path/to/bio-tissue-networks.tar.gz \
  --graphsage-zip /path/to/graphsage_ppi.zip \
  --output-dir biosnap_ppi_audit_results \
  --delete-raw-after-package
```

The deletion option is gated on successful gzip parsing, exact OhmNet-union equality, and subset inclusion in the global network. On failure, raw files are retained for diagnosis.
