# B104G bundle contents

This bundle contains the complete B104G analysis, independent validations, full 56,944-row Entrez map, compact retained inputs, scripts, logs, reports, and prebundle provenance records.

It deliberately excludes:

- the raw `graphsage_ppi.zip` and `bio-tissue-networks.tar.gz` archives, which remain listed with canonical URLs and SHA-256 values;
- the four uncompressed uploaded dhimmel TSVs, which are retained as deterministic byte-exact gzip files;
- raw files from prior batches when compact normalized derivatives are sufficient;
- the final external ledger row containing this bundle's own hash, to avoid a self-referential checksum.

Use `B104G_REPRODUCTION_INSTRUCTIONS_20260829T151452Z.md` for the rerun command and expected matrix hashes.
