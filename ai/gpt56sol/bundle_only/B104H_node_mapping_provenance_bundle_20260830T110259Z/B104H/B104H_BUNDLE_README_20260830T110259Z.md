# B104H mapping and provenance package

This package releases the complete GraphSAGE PPI node-to-Entrez mapping in compact and evidence-rich forms.

The mapping is exact with respect to all available data: every assigned row reproduces its OhmNet tissue-neighbor set, 50-dimensional feature vector, and 121-dimensional GO label vector. Evidence tiers distinguish identities independently resolved before the legacy-Python order reconstruction from identities inferred by that historical order mechanism.

The package also records:

- the current evidence-graded source-provenance assessment;
- the unsuccessful broad search for a public copy with ordered label names;
- a low-storage script for the remaining BioSNAP upstream-PPI audit;
- the saved randomized-label leakage experiment design;
- prebundle manifests and append-only provenance events.

`build_B104H_node_mapping_artifacts.py` is the exact script used to create and validate both mapping tables from the retained B104G compact inputs and the original GraphSAGE/OhmNet archives.
